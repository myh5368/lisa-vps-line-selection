## 哪些情况不该买这家

**只想要便宜。** 199 元/年已经是这条线的底线，但如果你的需求是“月付几块钱能跑就行”，且不在乎 IP 属性，市面上有更便宜的选择。丽萨主机的溢价在 IP 上。

**纯建站且不需要原生 IP。** CN2 GIA 有防御是优势，但端口小、单价高，且默认非原生 IP。如果站点只是普通企业站、不涉及平台风控，普通高防主机更省钱。

**指望非原生 IP 年付款解锁流媒体。** 199 元/年那款明确是非原生 IP，解锁能力弱。要解锁 Netflix、Disney+、HBO Max、TikTok、ChatGPT，得选原生 IP 或双 ISP 住宅 IP 的套餐，买之前看套餐描述这一栏。

**需要国内直连的低延迟。** 纽约、新加坡、台湾、英国这些节点都不是大陆优化线路，官方自己建议用香港或日本中转。要低延迟直连，看香港 CMI 系列，或者洛杉矶 9929。

**认为买了就不会被封 IP。** 任何 VPS 都不能保证 IP 永不被封，住宅 IP 只是把概率压低。真被封了就提工单换，这是常规操作，不是事故。

## 常见问题

**9929、4837、CN2 GIA 到底怎么选？**
看你的瓶颈在哪。瓶颈是国内访问速度 → 9929；瓶颈是流量和带宽 → 4837；瓶颈是攻击和稳定性 → CN2 GIA；瓶颈是 IP 被平台识别 → 家宽 VDS。四个问题里只有一个是真的瓶颈，按那个选。

**月付还是年付？**
第一次用这家，先月付跑一个月，确认线路和 IP 在你的实际场景里表现合格，再转年付。年付单价确实低，但一次性付出去的钱换不回来——虽然有 48 小时退款，那也只够你测两天。

**电信、联通、移动各自哪个快？**
洛杉矶 9929 三网回程都走 AS9929，移动去程经香港 CMI，延迟反而最低（测评口径约 100ms），电信在 150–180ms，联通居中偏好。香港 CMI 是三网延迟最低的机房，但 IP 属性和美国段不同，不能互相替代。

**IP 被封了怎么办？**
提工单申请更换，开通 48 小时内有一次免费换 IP 的机会，部分年付套餐也支持免费更换。换之前先确认是真的被封，还是本地网络或目标平台的问题。

**能装 Windows 吗？**
4837 系列、纽约家宽、VDS 系列明确支持。9929 和 CN2 GIA 的支持情况各资料说法不一，以购买页说明为准，有硬性需求下单前先问客服。

**48 小时退款怎么用？**
机器开通后 48 小时内提交，无条件原路退回，不需要理由。这条政策直接显示在控制面板里。它的实际用途是：拿两天时间验证 IP 属性、延迟、解锁表现，不合适就退。
